### control/src/main.rs

Rust binary. Does the following:
- Connects to ArduPilot FC via env var `MAVLINK_CONN` (default `udpin:0.0.0.0:14551`). Uses `mavlink` crate with `ardupilotmega` feature.
- Opens Zenoh session via `zenoh::Config::from_env()`.
- Declares publisher on topic `control/out/state`.
- Spawns two threads: `heartbeat_loop` (sends MAVLink HEARTBEAT to FC at 1 Hz) and `receiver_loop`.
- In `receiver_loop`: matches `MavMessage::HIL_STATE_QUATERNION(data)` and calls `publish_state(state_pub, &data)`.
- The `_ =>` arm currently just prints the message name and discards.
- Has SIYI A8 Mini gimbal UDP socket bound at `192.168.144.25:37260`. Gimbal state subscriber exists but gimbal publish to Zenoh is not yet wired.
- `publish_state` builds a FlatBuffers `StateVector` (from `state_generated.rs`) and puts it on `control/out/state`.
- Shutdown via `ctrlc` handler + `Arc<AtomicBool>`.

### control/src/state_generated.rs

Auto-generated by flatc. Defines `mavlink_fb::StateVector`, a 64-byte packed struct with fields:
- `time_usec: u64` — MAVLink timestamp in microseconds
- `quaternion: [f32; 4]` — attitude quaternion [w, x, y, z]
- `rollspeed: f32`, `pitchspeed: f32`, `yawspeed: f32` — rad/s
- `pos: [i32; 3]` — [lat_degE7, lon_degE7, alt_mm] (divide by 1e7 for lat/lon degrees, by 1000 for alt meters)
- `vel: [i16; 3]` — [vx_cms, vy_cms, vz_cms] NED frame (divide by 100.0 for m/s)
- `acc: [i16; 3]` — [xacc_mG, yacc_mG, zacc_mG] (divide by 1000.0 for m/s^2)
- `ind_airspeed: u16`, `true_airspeed: u16` — cm/s

### control/src/gimbal_generated.rs

Auto-generated by flatc. Defines `gimbal::State` FlatBuffers table with:
- `yaw: f32` — degrees
- `pitch: f32` — degrees
- `zoom: f32` — zoom factor

### navigation/src/main.rs

Rust binary. Do not modify. Does:
- Subscribes to `vehicle/heartbeat/fc`, `vehicle/heartbeat/camera`, `vehicle/heartbeat/gimbal`, `vehicle/heartbeat/air_unit`.
- Maintains `Watchdog` with `last_seen: HashMap<Component, Instant>`.
- Thresholds: `degraded_ms=1000`, `critical_ms=3000`, `failsafe_ms=7000`.
- Every 100ms: evaluates worst component age, publishes JSON string to `guidance/supervisor/signal`:
  `{"ts_ms":N,"state":"Nominal","action":"Continue","reason":"..."}`.
- State escalation: Nominal→Degraded→Critical→Failsafe → action Continue/Hold/Rtl/Abort.
- navigation watchdog BLOCKS ALL MISSION COMMANDS if state != Nominal, because guidance-bridge reads supervisor/signal and gates dispatch.

CRITICAL: `vehicle/heartbeat/fc` must receive any payload at least once every 1000ms or navigation will escalate. Currently nothing publishes this topic. This is a build priority.

## Decision: FlatBuffers Replaces JSON as Wire Format

JSON is not used on the hot path in the integrated system. Rationale:
- All processes are co-located on a single Jetson Orin NX. No network serialization benefit from text format.
- `control` already uses FlatBuffers (StateVector). Extending this to all topics is consistent.
- FlatBuffers: zero-copy reads, no parse heap allocation, schema-enforced contracts, ~10x smaller than JSON for telemetry payloads at 50 Hz.
- Python `flatbuffers` runtime exists and works. The guidance stack can consume FlatBuffers.
- `control-telemetry-adapter` as a separate process is ELIMINATED if `control` directly publishes semantic `VehicleTelemetry` FlatBuffer on `vehicle/telemetry/fc`. This removes an entire process and a Zenoh round-trip.

JSON is retained ONLY for:
- `logs/mission_dispatch.jsonl` replay logger (write-once, offline, human-readable)
- `guidance-publish-command` CLI tool (developer convenience, not on flight path)
- Navigation watchdog supervisor signal can stay JSON-string format short-term since it's very low frequency (10 Hz) and navigation is pure Rust with no FlatBuffers dependency yet. Migration to FlatBuffers is a P2 item.

MAVLink dispatch logic:
```rust
fn dispatch_mission_command(
    vehicle: &Arc<Connection<MavMessage>>,
    cmd: &MissionCommand,  // from generated FlatBuffers
) -> AckStatus {
    match cmd.command_type() {
        CommandType::ARM => {
            let msg = MavMessage::COMMAND_LONG(COMMAND_LONG_DATA {
                command: MavCmd::MAV_CMD_COMPONENT_ARM_DISARM,
                param1: 1.0,  // 1=arm, 0=disarm
                target_system: 1, target_component: 1,
                ..Default::default()
            });
            vehicle.send_default(&msg).map(|_| AckStatus::ACCEPTED).unwrap_or(AckStatus::FAILED)
        }
        CommandType::TAKEOFF => {
            let alt = cmd.target_alt_m();
            let msg = MavMessage::COMMAND_LONG(COMMAND_LONG_DATA {
                command: MavCmd::MAV_CMD_NAV_TAKEOFF,
                param7: alt,
                target_system: 1, target_component: 1,
                ..Default::default()
            });
            vehicle.send_default(&msg).map(|_| AckStatus::ACCEPTED).unwrap_or(AckStatus::FAILED)
        }
        CommandType::GOTO => {
            // SET_POSITION_TARGET_GLOBAL_INT
            let msg = MavMessage::SET_POSITION_TARGET_GLOBAL_INT(
                mavlink::ardupilotmega::SET_POSITION_TARGET_GLOBAL_INT_DATA {
                    lat_int: (cmd.target_lat_deg() * 1e7) as i32,
                    lon_int: (cmd.target_lon_deg() * 1e7) as i32,
                    alt: cmd.target_alt_m(),
                    type_mask: 0b0000_111111111000,  // use position only
                    coordinate_frame: mavlink::ardupilotmega::MavFrame::MAV_FRAME_GLOBAL_RELATIVE_ALT_INT,
                    target_system: 1, target_component: 1,
                    ..Default::default()
                }
            );
            vehicle.send_default(&msg).map(|_| AckStatus::ACCEPTED).unwrap_or(AckStatus::FAILED)
        }
        CommandType::RTL => {
            let msg = MavMessage::COMMAND_LONG(COMMAND_LONG_DATA {
                command: MavCmd::MAV_CMD_NAV_RETURN_TO_LAUNCH,
                target_system: 1, target_component: 1,
                ..Default::default()
            });
            vehicle.send_default(&msg).map(|_| AckStatus::ACCEPTED).unwrap_or(AckStatus::FAILED)
        }
        CommandType::LAND => {
            let msg = MavMessage::COMMAND_LONG(COMMAND_LONG_DATA {
                command: MavCmd::MAV_CMD_NAV_LAND,
                target_system: 1, target_component: 1,
                ..Default::default()
            });
            vehicle.send_default(&msg).map(|_| AckStatus::ACCEPTED).unwrap_or(AckStatus::FAILED)
        }
        CommandType::HOLD => {
            // Switch to LOITER mode via MAV_CMD_DO_SET_MODE
            // ArduPilot LOITER mode = custom_mode 5
            let msg = MavMessage::COMMAND_LONG(COMMAND_LONG_DATA {
                command: MavCmd::MAV_CMD_DO_SET_MODE,
                param1: MavModeFlag::MAV_MODE_FLAG_CUSTOM_MODE_ENABLED.bits() as f32,
                param2: 5.0,  // LOITER
                target_system: 1, target_component: 1,
                ..Default::default()
            });
            vehicle.send_default(&msg).map(|_| AckStatus::ACCEPTED).unwrap_or(AckStatus::FAILED)
        }
        CommandType::PAYLOAD_RELEASE => {
            // AUX1 servo to 1900us (open)
            let msg = MavMessage::COMMAND_LONG(COMMAND_LONG_DATA {
                command: MavCmd::MAV_CMD_DO_SET_SERVO,
                param1: 9.0,     // AUX1 = servo 9
                param2: 1900.0,  // 1900us = open
                target_system: 1, target_component: 1,
                ..Default::default()
            });
            vehicle.send_default(&msg).map(|_| AckStatus::ACCEPTED).unwrap_or(AckStatus::FAILED)
        }
        CommandType::PAYLOAD_SECURE => {
            let msg = MavMessage::COMMAND_LONG(COMMAND_LONG_DATA {
                command: MavCmd::MAV_CMD_DO_SET_SERVO,
                param1: 9.0,     // AUX1
                param2: 1100.0,  // 1100us = closed
                target_system: 1, target_component: 1,
                ..Default::default()
            });
            vehicle.send_default(&msg).map(|_| AckStatus::ACCEPTED).unwrap_or(AckStatus::FAILED)
        }
        _ => AckStatus::REJECTED,
    }
}
```

    import flatbuffers
    from guidance.generated.guidance import MissionCommand as FbMissionCommand
    builder = flatbuffers.Builder(256)
    # build string fields first (FlatBuffers rule: scalars inline, strings/tables before finish)
    command_id = builder.CreateString(command.command_id)

    FbMissionCommand.AddTimeoutSec(builder, command.timeout_sec)
    FbMissionCommand.AddSafetyMode(builder, safety_mode)
    cmd = FbMissionCommand.End(builder)
    builder.Finish(cmd)
    return bytes(builder.Output())

### mujoco-sim/src/main.rs

```rust
use std::time::Duration;
use zenoh::Wait;

mod sim;
mod publisher;
mod actuation;

fn main() -> zenoh::Result<()> {
    let session = zenoh::open(
        zenoh::Config::from_env().unwrap_or(zenoh::Config::default())
    ).wait()?;

    let state_pub = session.declare_publisher("sim/mujoco/state").wait()?;
    let cmd_sub = session.declare_subscriber("guidance/mission/command").wait()?;
    // Publish heartbeat so navigation watchdog does not escalate in sim mode
    let fc_heartbeat_pub = session.declare_publisher("vehicle/heartbeat/fc").wait()?;
    let gimbal_heartbeat_pub = session.declare_publisher("vehicle/heartbeat/gimbal").wait()?;
    let camera_heartbeat_pub = session.declare_publisher("vehicle/heartbeat/camera").wait()?;

    let mut drone_sim = sim::DroneSim::load("models/drone.xml");
    let mut tick: u32 = 0;

    loop {
        drone_sim.step();
        let state = drone_sim.state();
        let payload = publisher::serialize_state(&state);
        state_pub.put(payload).wait()?;

        // Navigation watchdog needs heartbeats. In sim, all components are "present".
        // Publish at ~10Hz (every 5 ticks of 50Hz loop).
        if tick % 5 == 0 {
            fc_heartbeat_pub.put(b"1".as_ref()).wait()?;
            gimbal_heartbeat_pub.put(b"1".as_ref()).wait()?;
            camera_heartbeat_pub.put(b"1".as_ref()).wait()?;
        }

        // Drain pending commands non-blocking
        while let Ok(sample) = cmd_sub.try_recv() {
            let bytes = sample.payload().to_bytes();
            actuation::apply_command(&mut drone_sim, &bytes);
        }

        tick = tick.wrapping_add(1);
        std::thread::sleep(Duration::from_millis(20)); // 50 Hz
    }
}
```

// Wraps MuJoCo model and data lifecycle.
// STUB: replace mj_step call with actual mujoco-sys unsafe calls when mujoco-sys is wired.
// The public API (load, step, state, apply_throttle) must not change.

pub struct DroneSim {
    pub pos: [f64; 3],   // [x_m, y_m, z_m] local NED from origin (z-down, so negative = up)
    pub vel: [f64; 3],   // [vn_mps, ve_mps, vd_mps]
    pub battery: f64,    // 0.0 - 100.0
    pub mode: String,    // "GUIDED", "LOITER", "RTL", etc.
    origin_lat: f64,
    origin_lon: f64,
}

impl DroneSim {
    pub fn load(_model_path: &str) -> Self {
        // TODO: use mujoco_sys::MjModel::load_xml(model_path) for real physics
        Self {
            pos: [0.0, 0.0, -10.0],  // 10m AGL (NED: z negative = up)
            vel: [0.0; 3],
            battery: 100.0,
            mode: "GUIDED".to_string(),
            // Cal Poly SLO airfield approximate origin
            origin_lat: 35.3272,
            origin_lon: -120.7821,
        }
    }

    pub fn step(&mut self) {
        // TODO: mj_step(self.model, self.data)
        // Stub: integrate position from velocity at 50 Hz dt
        let dt = 0.02_f64;
        self.pos[0] += self.vel[0] * dt;
        self.pos[1] += self.vel[1] * dt;
        self.pos[2] += self.vel[2] * dt;
        // Drain battery slowly: 0.001% per step = ~28 minutes flight
        self.battery = (self.battery - 0.001).max(0.0);
    }

    pub fn state(&self) -> super::publisher::SimState {
        // Convert local NED meters to geodetic degrees
        let lat = self.origin_lat + self.pos[0] / 111_111.0;
        let lon = self.origin_lon
            + self.pos[1] / (111_111.0 * self.origin_lat.to_radians().cos());
        let alt = -self.pos[2]; // NED z-down to alt positive-up

        super::publisher::SimState {
            lat_deg:     lat,
            lon_deg:     lon,
            alt_m:       alt,
            vn_mps:      self.vel[0],
            ve_mps:      self.vel[1],
            vd_mps:      self.vel[2],
            battery_pct: self.battery,
            flight_mode: self.mode.clone(),
        }
    }

    pub fn apply_throttle(&mut self, throttle_normalized: f64) {
        // throttle 0.0-1.0 maps to climb rate -5.0 to +5.0 m/s (NED: negative = up)
        self.vel[2] = -(throttle_normalized - 0.5) * 10.0;
    }

    pub fn apply_goto(&mut self, lat_deg: f64, lon_deg: f64, alt_m: f64) {
        // Naive proportional guidance: compute NED offset and set velocity toward target
        let north_offset = (lat_deg - self.origin_lat) * 111_111.0 - self.pos[0];
        let east_offset = (lon_deg - self.origin_lon)
            * (111_111.0 * self.origin_lat.to_radians().cos())
            - self.pos[1];
        let down_offset = -alt_m - self.pos[2]; // NED z-down
        let dist = (north_offset.powi(2) + east_offset.powi(2) + down_offset.powi(2)).sqrt();
        let speed = 5.0_f64; // m/s cruise
        if dist > 0.5 {
            self.vel[0] = speed * north_offset / dist;
            self.vel[1] = speed * east_offset / dist;
            self.vel[2] = speed * down_offset / dist;
        } else {
            self.vel = [0.0; 3]; // arrived
        }
    }
}

pub struct SimState {

// Output JSON on sim/mujoco/state.
// This topic is sim-internal only. The guidance MuJoCoTelemetryAdapter consumes this
// and translates to FlatBuffers VehicleTelemetry on vehicle/telemetry/fc.
// Uses nested format expected by MuJoCoTelemetryAdapter (see mujoco_telemetry.py).
pub fn serialize_state(state: &SimState) -> Vec<u8> {
    let ts_ms = SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .unwrap_or_default()
        .as_millis() as u64;

    format!(
        r#"{{"timestamp_ms":{ts_ms},"position":{{"lat_deg":{lat},"lon_deg":{lon},"alt_m":{alt}}},"velocity_ned":{{"vn_mps":{vn},"ve_mps":{ve},"vd_mps":{vd}}},"battery_pct":{bat},"flight_mode":"{mode}","link_quality":1.0}}"#,
        ts_ms = ts_ms,
        lat = state.lat_deg,
        lon = state.lon_deg,
        alt = state.alt_m,
        vn = state.vn_mps,
        ve = state.ve_mps,
        vd = state.vd_mps,
        bat = state.battery_pct,
        mode = state.flight_mode,
    ).into_bytes()
}

// Receives FlatBuffers MissionCommand bytes from guidance/mission/command.
// Translates to sim physics calls.
// If FlatBuffers decode fails, log and skip — never panic in sim loop.
pub fn apply_command(sim: &mut DroneSim, payload: &[u8]) {
    // Attempt FlatBuffers decode of MissionCommand
    // Generated code will be at src/generated/ once flatc runs on schemas/mission_command.fbs
    // TODO: replace JSON fallback with flatbuffers decode after codegen
    
    // Temporary JSON fallback for bring-up:
    if let Ok(text) = std::str::from_utf8(payload) {
        if let Ok(val) = serde_json::from_str::<serde_json::Value>(text) {
            match val.get("command_type").and_then(|v| v.as_str()) {
                Some("goto") => {
                    let lat = val.get("target_lat_deg").and_then(|v| v.as_f64()).unwrap_or(sim.origin_lat());
                    let lon = val.get("target_lon_deg").and_then(|v| v.as_f64()).unwrap_or(sim.origin_lon());
                    let alt = val.get("target_alt_m").and_then(|v| v.as_f64()).unwrap_or(10.0);
                    sim.apply_goto(lat, lon, alt);
                }
                Some("rtl") => {
                    sim.apply_goto(sim.origin_lat(), sim.origin_lon(), 10.0);
                    sim.mode = "RTL".to_string();
                }
                Some("hold") => { sim.vel = [0.0; 3]; sim.mode = "LOITER".to_string(); }
                Some("land") => { sim.vel = [0.0, 0.0, 0.5]; sim.mode = "LAND".to_string(); } // vd positive = descend
                _ => {}
            }
        }
    }
}

## Topic Map (Final, All Formats)

All topics are FlatBuffers except where noted. "sim-only" means the topic does not exist in hardware mode.

| Topic | Format | Producer | Consumer |
|---|---|---|---|
| `vehicle/telemetry/fc` | FlatBuf VehicleTelemetry | `control` (hw) OR `guidance-mujoco-telemetry` (sim) | Mission FSMs, guidance-bridge |
| `vehicle/heartbeat/fc` | empty bytes | `control` (hw) OR `mujoco-sim` (sim) | navigation watchdog |
| `vehicle/heartbeat/camera` | empty bytes | vision-pipeline (future) OR `mujoco-sim` (sim) | navigation watchdog |
| `vehicle/heartbeat/gimbal` | empty bytes | `control` (hw) OR `mujoco-sim` (sim) | navigation watchdog |
| `vehicle/heartbeat/air_unit` | empty bytes | `control` via SYS_STATUS (hw) OR `mujoco-sim` (sim) | navigation watchdog |
| `guidance/mission/command` | FlatBuf MissionCommand | Mission FSMs via guidance-bridge | `control` (hw) OR `mujoco-sim` actuation (sim) |
| `guidance/mission/ack` | FlatBuf CommandAck | `control` (hw) OR sim actuation (sim) | guidance-ack-monitor, FSMs |
| `guidance/supervisor/signal` | JSON string (navigation Rust output, migrate later) | navigation watchdog | guidance-bridge gate |
| `control/out/state` | FlatBuf StateVector | `control` only | internal (keep for raw data consumers / debugging) |
| `control/out/gimbal` | FlatBuf gimbal::State | `control` only | future vision-pipeline for geo_project() |
| `sim/mujoco/state` | JSON | `mujoco-sim` (sim-only) | `guidance-mujoco-telemetry` |
